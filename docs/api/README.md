# API 规格模板

- **范围说明**：涉及的业务功能与接口列表。
- **认证与权限**：鉴权方式、角色/权限检查、速率限制。
- **版本与兼容性**：版本策略、向后兼容约定。
- **公共约定**：路径前缀、内容类型、分页/过滤/排序规范。
- **接口定义（逐个接口）**：
  - 路径与方法
  - 描述与调用场景
  - 请求参数（路径、查询、头、体），含示例
  - 响应体与示例，状态码
  - 幂等性、重试、错误码与错误示例
- **依赖与集成点**：下游/上游接口、消息、队列、Webhook。
- **性能与安全**：限流、缓存策略、数据脱敏/加密。
- **监控与调试**：关键指标、日志字段、追踪信息。
