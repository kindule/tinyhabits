# 🎮 核心玩法循环设计

> 好的游戏不是"功能列表",而是"循环的体验"。玩家不是在完成任务,而是在一个循环中自然地成长。

---

## 一、核心循环概述

### 1.1 五步闭环

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│                        核心玩法循环                              │
│                                                                 │
│      ┌─────────┐                              ┌─────────┐       │
│      │ 1. 探索 │ ─────────────────────────────▶ │ 2. 发现 │      │
│      │  愿望   │                               │  行为   │      │
│      └────┬────┘                               └────┬────┘      │
│           │                                         │           │
│           │      ┌─────────────────────┐           │           │
│           │      │     5. 成长解锁      │           │           │
│           │      │   (能力/地图/玩法)   │           │           │
│           │      └──────────┬──────────┘           │           │
│           │                 │                      │           │
│           │                 │                      │           │
│      ┌────▼────┐           │           ┌──────────▼────┐      │
│      │ 4. 反馈 │ ◀──────────┴───────────│ 3. 施放咒语   │      │
│      │  奖励   │                        │ (每日微行动)  │      │
│      └─────────┘                        └───────────────┘      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 循环详解

| 阶段 | 游戏行为 | 现实对应 | 频率 |
|------|---------|---------|------|
| **1. 探索愿望** | 愿望排序游戏 + 选择愿望城 | 澄清人生优先级 | 每7天1次 |
| **2. 发现行为** | 行为工坊:召唤/裂变/合成 | 探索可行的微行为 | 首次必须,后续可选 |
| **3. 施放咒语** | 每日完成1张微行动卡 | 执行具体微习惯 | 每天1次 |
| **4. 反馈奖励** | 击碎裂隙 + 鼓励台词 + Day推进 | 获得即时正反馈 | 每次完成 |
| **5. 成长解锁** | 愿望城进化 + 咒语图鉴 | 感受累积进步 | 持续累积 |

### 1.3 时间维度的循环嵌套

## 二、入口循环:探索愿望

### 2.1 愿望排序游戏

> **设计目标**: 让用户完成一次"内心优先级博弈",而非简单填表。

#### 两两对决模式

```
游戏规则:
- 每轮随机展示2张愿望卡
- 用户选择"更想靠近的那个"
- 共进行7轮对决
- 系统统计每张卡的胜场数
- 胜场越多,排名越高

心理设计:
- 两两对决减少选择困难(只选1个而非排序12个)
- 随机配对增加博弈感("没想到健康和自由要二选一")
- 胜场统计暗示"这是你真正在乎的"
```

#### 对决界面设计

```
===[ 顶部对话框 ]===
Arc: "如果只能靠近一个,你会选择...?"

===[ 中部:两张愿望卡左右并列 ]===

┌──────────────┐          ┌──────────────┐
│              │          │              │
│     🏥        │    VS    │     💰        │
│   「健康」    │          │   「财富」    │
│              │          │              │
│  精力充沛    │          │  财务自由    │
│  身体健康    │          │  安全感     │
│              │          │              │
└──────────────┘          └──────────────┘

===[ 底部进度 ]===
第 3/7 轮

===[ 点击任一卡片选择,有弹跳反馈 ]===
```

### 2.2 命运盘确认

```
对决完成后,进入命运盘页面:

===[ 三圈命运盘 ]===

                    ┌───────────────────┐
                    │                   │
                    │   「核心愿望」     │
                    │    (1个)          │
                    │                   │
          ┌─────────┼───────────────────┼─────────┐
          │         │                   │         │
          │   「主线愿望」(2-3个)      │         │
          │         │                   │         │
          │         └───────────────────┘         │
          │                                       │
          │         「以后再说」(其余)            │
          │                                       │
          └───────────────────────────────────────┘

操作方式:
- Top 1 自动进入"核心愿望"
- 用户可点击替换核心愿望
- 拖拽为增强版(MVP可选)

确认后:
- 生成"愿望城名称"
- 存储 currentWish
- 进入行为工坊
```

## 三、核心循环:行为工坊

### 3.1 设计理念

```
传统习惯App:              行为工坊:
───────────────           ─────────────
问: "你想养成什么习惯?"    问: "让我帮你召唤一些灵感~"
用户: 输入文字             用户: 点击选择
↓                         ↓
结果: 用户填写任务         结果: 用户探索可能性

关键区别:
- 不是输入,是选择
- 不是承诺,是探索
- 不是完美设定,是素材收集
```

### 3.2 工坊三大核心操作

#### 🔮 召唤灵感 (Summon)

```
触发: 点击「召唤灵感」按钮
动画: 3个行为气泡依次从水晶球弹出(stagger 80ms)
规则: 从行为库按当前愿望分类随机抽取3个
交互: 用户选择1个,加入素材区

===[ 界面 ]===

MIA: "让我为你召唤一些灵感泡泡~"

        ┌───────┐
        ╱  ✨   ╲        ←── 愿望水晶(发光呼吸)
       ╱         ╲
      └───────────┘

   🫧喝一杯水   🫧站起来伸展   🫧深呼吸3次
                                        ←── 行为气泡(可点击)

[ 召唤灵感 ]  [ 裂变 ]  [ 合成 ]

素材区: [已选行为1] [已选行为2] ...
```

#### ⚡ 行为裂变 (Split)

```
触发: 选中素材区的一个行为,点击「裂变」
动画: 一个气泡变成3个更小气泡(裂变动画)
规则: 从裂变规则库匹配,生成3个更小行为
目的: 把"较大行为"拆解为"极小行为"

===[ 裂变前 ]===
选中: 🫧 每天跑步

===[ 裂变后 ]===
生成: 🫧穿上跑鞋  🫧站起来  🫧走到门口

===[ MIA对话 ]===
MIA: "裂变启动!把宏大计划拆成一步就行~"
MIA: "选择你觉得最容易的那个!"
```

#### 🧪 行为合成 (Merge)

```
触发: 选中素材区的2个行为,点击「合成」
动画: 两个气泡旋转合并,新卡闪光出现
规则: 拼接生成新咒语名称(模板命名)
目的: 创造个性化的"组合咒语"

===[ 合成前 ]===
选中: 🫧喝水 + 🫧伸展

===[ 合成后 ]===
生成: ✨「水润舒展」咒语
      (喝一杯水后做个伸展)

===[ MIA对话 ]===
MIA: "哇!新咒语诞生了!"
```

### 3.3 AI锚点绑定

```
时机: 用户选择行为后,自动触发
流程:
1. MIA引导: "让我为你找找合适的时机~"
2. AI生成3-5个锚点建议
3. 用户选择锚点
4. 行为气泡显示"[锚点] → [行为]"

===[ 界面 ]===

MIA: "让我为你找找合适的时机~"
        
        ⏳ 正在召唤时机魔法...

===[ AI返回后 ]===

MIA: "找到了!这些时机适合施放这个咒语~"

   🌅 起床后      🪥 刷牙后      ☕ 喝咖啡时
   🍽️ 吃完饭后    🌙 睡前

===[ 选择后,行为气泡更新 ]===

   🫧 🪥刷牙后 → 喝一杯水
```

### 3.4 生成卡组

```
触发: 点击「生成今日卡组」
规则: 从素材区选择行为,生成3张卡
AI检查: MAP评估(动机+能力+提示)

===[ 卡组结构 ]===

┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ★ 保底卡         ★★ 主线卡         ✨ 彩蛋卡              │
│   30-60秒          2-5分钟            10-30秒                 │
│   难度极低          难度中等           趣味性                  │
│   "再废也能完成"    "需要一点努力"     "意外惊喜"              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

===[ AI MAP评估 ]===

MIA: "让我检查一下这副卡组~"

检查维度:
- 动机(M): 行为与核心愿望的关联性
- 能力(A): 行为的时间/精力门槛
- 提示(P): 锚点是否清晰明确

如有问题:
MIA: "这个行为有点长哦,要不要缩短?"
用户选择: [返回修改] 或 [强制生成]
```

## 四、日常循环:每日一张卡

### 4.1 每日进入流程

```
用户打开App → 自动进入Daily页 → 显示今日卡片

===[ 判断逻辑 ]===

if (未完成角色创建) → 跳转 Role 页
if (未完成愿望排序) → 跳转 Wishes 页
if (未生成卡组) → 跳转 Workshop 页
else → 显示 Daily 页
```

### 4.2 卡片抽取规则

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   卡片抽取概率表                                                │
│                                                                 │
│   连续完成天数    保底卡    主线卡    彩蛋卡                    │
│   ────────────  ────────  ────────  ────────                   │
│   首次/断连       100%       0%       0%                       │
│   连续1天         100%       0%       0%                       │
│   连续2天+         60%      30%      10%                       │
│                                                                 │
│   设计意图:                                                     │
│   - 初期用保底卡建立信心                                        │
│   - 连续后增加变化和挑战                                        │
│   - 彩蛋卡增加惊喜感                                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.3 救援卡机制

```
if (昨日未完成) {
    今日卡片 = 救援卡
    提示 = "救援咒语已准备好,微光不会消失"
}

救援卡来源:
- 优先: 用户卡组中的保底卡
- 备选: 预置救援卡池(极简行为)

设计意图:
- 不惩罚用户(不扣分/不掉级)
- 降低回归门槛
- 温和的心理安全感
```

### 4.4 完成反馈三段式

```
这是游戏最关键的"爽点",必须精细设计。

===[ 第一段:裂隙宣言滑入 ]===

          ↓ (从底部滑入)
    ┌─────────────────────────┐
    │   🌑                    │
    │   "今天太累了,算了吧..."  │
    │                         │
    │      [ 击碎裂隙 ]        │
    └─────────────────────────┘

===[ 第二段:击碎动画 ]===

    ┌─────────────────────────┐
    │                         │
    │     💥 抖动 → 碎片散开    │
    │         ✨✨✨           │
    │                         │
    └─────────────────────────┘
    
    (背景变亮一点点)

===[ 第三段:Arc鼓励 ]===

    🌟 Arc: "你做到了最难的一步:开始。"
    
    ┌─────────────────────────┐
    │   Day 2 完成!           │
    │   积分 +10              │
    │   连续 2 天             │
    └─────────────────────────┘
```

## 六、循环平衡设计

### 6.1 时间投入

| 环节 | 首次耗时 | 日常耗时 |
|------|---------|---------|
| Onboarding (世界观) | 30秒 | - |
| Role (天赋选择) | 1分钟 | - |
| Wishes (愿望排序) | 3-5分钟 | 每7天一次 |
| Workshop (行为工坊) | 3-5分钟 | 可选,约1分钟 |
| Daily (完成微行动) | 1-3分钟 | 1-3分钟 |
| **总计首日** | ~10-15分钟 | - |
| **日常** | - | ~2分钟 |

### 6.2 难度曲线

```
难度 ↑
     │
  中  │                              ★★ 主线卡
     │                         ↗
     │              ★ 保底卡  ──────
  低  │         ↗
     │    ────
     │  ↗
     │
     └──────────────────────────────────────────→ 连续天数
           Day1   Day2   Day3   Day4   Day5
           
设计意图:
- Day1-2: 只出保底卡,建立信心
- Day3+: 开始混入主线卡,增加挑战
- 彩蛋卡随机出现,增加惊喜
```

### 6.3 奖励节奏

```
奖励类型     频率           内容
─────────  ─────────     ──────────────────
即时奖励    每次完成       击碎动画 + 鼓励台词 + 积分
日奖励      每天完成       Day+1 + Streak更新
周奖励      Day7完成       愿望城修复动画 + 选择新城
收集奖励    积累           咒语图鉴解锁
成长奖励    里程碑         Streak徽章(3/7/30/100天)
```

## 七、防流失设计

### 7.1 首日流失防护

| 流失点 | 风险 | 对策 |
|--------|------|------|
| 世界观太长 | 用户跳过 | 控制在30秒内,可一键跳过 |
| 天赋选择困难 | 用户放弃 | 强调"没有对错" |
| 愿望排序太久 | 用户疲劳 | 7轮对决,不超过3分钟 |
| 工坊太复杂 | 用户困惑 | MIA步步引导,有默认选项 |
| 首日任务失败 | 信心受挫 | 保底卡极简,必能完成 |

### 7.2 日常流失防护

| 流失点 | 风险 | 对策 |
|--------|------|------|
| 某天没完成 | 羞愧不回来 | 救援卡机制,温和提示 |
| 连续断签 | 觉得失败 | 不显示断签,只显示"微光等你" |
| 觉得没意义 | Day4质疑 | MIA剧情引导,强化微小价值 |
| 觉得重复 | Day5+疲劳 | 主线卡+彩蛋卡增加变化 |

### 7.3 用户回归设计

```
用户断签后回归:

===[ 打开App ]===

Arc: "欢迎回来,微光法师。"
Arc: "微光不会因为休息而消失。"

===[ 界面 ]===

- 不显示"你已经断签X天"
- 显示"救援咒语已准备好"
- Streak从1开始(不惩罚)
- 一切如常继续

===[ 设计意图 ]===

用户断签的心理状态:
- 羞愧 → 回避 → 流失

我们的应对:
- 温和迎接 → 降低门槛 → 继续
```

## 八、循环扩展(未来)

> 以下为MVP后的扩展方向。

### 8.1 角色成长线(V2)

```
行为学徒 → 微习惯训练师 → 行为设计师 → 人生架构师

升级解锁:
- 新玩法(行为组合/每日多卡)
- 新地图(更多愿望城皮肤)
- 新角色(解锁Lux光织者等)
- 新分析(行为复盘局)
```

### 8.2 世界成长线(V2)

### 8.3 认知成长线(V3)

```
完成3座愿望城后解锁:

- 行为复盘局: 分析哪些行为完成率高
- 动机分析: 探索核心动机
- 情绪地图: 记录完成时的情绪
- 自我画像: 生成个人行为画像
```

---

> 📝 **设计师笔记**: 核心循环的本质是"反馈循环"。玩家的每一个行动都要有明确的反馈,每一个反馈都要引向下一个行动。当玩家开始说"我每天都想打开看看会是什么卡",说明循环成功了。
