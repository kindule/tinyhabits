> 7天不只是"完成7次",而是一段完整的叙事体验。每一天都有独特的情绪节奏和剧情推进。

## 十、台词风格指南

### 10.1 Arc的台词规则

```
✅ 正确风格:
- 简短(不超过15字)
- 克制温暖
- 用陈述句,少用感叹号
- 肯定用户,不评判

示例:
✅ "你做到了。"
✅ "微光不会消失。"
✅ "最难的一步,是开始。"
✅ "不需要完美,只需要持续。"

❌ 避免:
- "太棒了!你真厉害!" → 过于空洞
- "加油哦~" → 过于轻浮
- "你怎么又没完成?" → 责备
```

### 10.2 MIA的台词规则

```
✅ 正确风格:
- 活泼(可用~和!)
- 鼓励探索
- 减少压力感
- 像一个好奇的朋友

示例:
✅ "让我帮你召唤一些灵感~"
✅ "试试看嘛~反正只是素材!"
✅ "那就让它更小,小到无法拒绝~"
✅ "太棒了!新咒语诞生了!"

❌ 避免:
- "你必须选择一个" → 过于强制
- "这个不太好" → 否定用户
- "快点完成" → 制造压力
```

### 10.3 Rift的台词规则

```
✅ 正确风格:
- 诱惑低语
- 合理但消极
- 可被击碎的轻量阻力
- 像耳边的杂念

示例:
✅ "今天太累了,算了吧..."
✅ "这点做了也没用..."
✅ "明天再开始也行..."
✅ "完美的时机还没到..."

❌ 避免:
- "你这么懒,注定失败" → 羞辱
- "你永远做不到" → 否定
- "别人都比你强" → 攀比
```
