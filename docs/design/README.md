# 产品介绍：DayDayUp 一款基于福格行为模型的成长类游戏

核心价值，基于游戏策略，形成好玩、有趣、有意义的长期习惯，不只是“记录习惯”，而是要做到三点：

* 让用户**愿意玩**（情绪价值、反馈、惊喜）
* 让用户**被引导思考**（愿望澄清、行为探索）
* 让用户**自然形成行为**（低摩擦、正反馈、成长感）

从**产品定位 → 世界观 → 核心玩法循环 → 关键系统设计 → 前期行为探索模块 → 长期留存机制**，的一套资深游戏设计视角的完整方案。

---

# 一、产品定位：这不是习惯App，是“人生技能养成游戏”

### 产品定义

> 一款基于福格行为模型的「人生愿望修炼游戏」，通过游戏化探索，把“我想要的人生”拆解成每天都能完成的微行动。

# 二、世界观设计

## 1. 世界观设定

用户进入的是一个世界：
👉 **「Tiny Realms 微界」**

每个人都是：
👉 **一名正在修炼的“行为魔法师 / 训练师 / 设计师”**

世界的基本设定：

* 愿望 = 世界中的“远方圣地 / 传说之城 / 终极形态”
* 行为 = 魔法咒语 / 技能碎片 / 生物种子
* 微习惯 = 最小可释放魔法
* 情绪与动机 = 魔法能量

## 2. 核心隐喻映射

| 福格模型 | 游戏表达        |
| ---- | ----------- |
| 愿望   | 传说地图 |
| 行为   | 魔法卡牌 |
| 能力   | 法力值  |
| 提示   | 精灵提醒 |
| 情绪奖励 | 进化动画 |

# 三、核心玩法循环

这个游戏的核心循环，是：

> 探索愿望 → 发现行为 → 试验行为 → 获得反馈 → 解锁成长 → 回到探索

可以抽象成一个五步闭环：

1. 探索人生地图（我想成为什么）
2. 收集行为素材（我能做什么）
3. 释放最小魔法（我今天做一个什么）
4. 获得世界反馈（奖励 / 变化 / 故事）
5. 角色成长解锁（能力、地图、玩法）

---

# 四、前期核心：行为探索一定要“像玩游戏”

# 模块一：愿望清单排序（拖拽+博弈感）

## 🎮 《人生卡组》

### 目标

👉 帮用户完成一次**内心优先级博弈**

### 玩法设计

### 1. 愿望以「卡牌」形式出现

每个愿望是一张卡牌，包含不限于：

* 健康
* 自由
* 财务安全
* 影响力
* 家庭
* 成就
* 爱情
* 探索

卡牌有属性：

* 模糊度
* 能量感
* 距离感
* 情绪色彩

### 2. 场景

#### ✅ 方案A：人生能量环

* 中心：此阶段最重要
* 中圈：重要
* 外圈：未来

用户拖卡牌时：

* 卡牌会“抗拒/吸附”
* 会触发提示语：

  * “你真的愿意把它放这么远吗？”
  * “这个愿望正在发光”

### 3. 输出 “命运图谱”

最后生成：

* 核心愿望 × 1
* 主线愿望 × 2~3
* 支线愿望 × 若干

这是后面所有玩法的主线地图。

---

# 模块二：行为集群（魔法师工坊）

## 🎮 玩法名：《行为炼金术》

### 目标

👉 让用户进入**发散状态 + 可能性感 + 低压力创造**

---

## 一、形式：魔法实验而不是表单

针对一个愿望，比如【更健康】

用户进入一个房间：

🏰 魔法工坊中间：愿望水晶
🌟 四周漂浮：行为气泡

用户不是打字，是：

* 点一个水晶球 → 出现“一个可能的行为”
* 拖动气泡 → 合并 / 拆分 / 变形
* 点魔法书 → 给灵感

---

## 二、核心机制设计

### 1. 行为不是“对错”，是“素材”

每个行为都是：

🧩 一个碎片
不是承诺，而是可能性。

例如：

* 喝水
* 站起来
* 去阳台
* 看一眼体脂秤
* 打开Keep

---

### 2. 魔法师引导结构

魔法师不问：
❌ 你应该做什么？

而问：

* “如果你很懒，也能做什么？”
* “如果只要30秒？”
* “如果不出门？”
* “如果不改变生活？”

这些对应福格模型的**能力设计**。

---

### 3. 行为裂变机制

比如用户写了：
👉「每天跑步」

系统触发魔法阵：

自动拆解为：

* 穿鞋
* 站起来
* 出门
* 走到楼下
* 走100米

用户可以点选保留。

这一步会非常“爽”，因为它让人感觉：
👉 原来事情可以变这么小。

---

### 4. 行为聚类系统

系统会自动把行为聚成几类：

* 启动型（触发）
* 最小型（保底）
* 成长型（挑战）
* 情绪型（奖励）

用户会看到一个“行为星系”。

---

## 三、产出物不是To-do，而是「魔法卡组」

最后用户不是得到一个清单，而是：

🎴 一副属于这个愿望的行为卡组
每张卡都有：

* 难度
* 时长
* 能量消耗
* 情绪回报

这为后续“每日任务生成器”服务。

---

# 五、从行为到习惯：每日玩法层

多邻国成功的不是“学习”，而是：

👉 每天我知道点进去会发生什么

## 每日核心玩法建议是：

🎮 《今日试验》

每天系统自动生成：

* 1 张【保底卡】（再废也能完成）
* 1 张【主线卡】
* 1 张【惊喜卡】

用户只需要做一件。

完成后：

* 有动画反馈
* 行为卡进化
* 愿望地图发生变化

不是打勾，是“世界在变”。

---

# 六、长期留存系统（像游戏一样活）

如果只做习惯，很容易死。

必须引入三条成长线：

---

## 1. 角色成长线

用户不是“打卡者”，而是：

* 行为学徒
* 微习惯训练师
* 行为设计师
* 人生架构师

升级解锁：

* 新玩法
* 新地图
* 新魔法师
* 新分析能力

---

## 2. 世界成长线

愿望大陆会变化：

* 荒地 → 村庄 → 城市 → 王国

这是**可视化人生进度条**。

---

## 3. 认知成长线（你这个产品最有价值的部分）

后期可以解锁：

* 行为复盘局
* 动机分析
* 情绪地图
* 自我画像

这是从“玩习惯”升级为“理解自己”。
