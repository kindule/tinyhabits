# 🎨 UI与交互规范

> 好的游戏UI不只是"好看",而是让玩家"感觉在玩"。每一次点击都要有反馈,每一个元素都要有意义。

---

## 一、视觉风格定义

### 1.1 整体风格

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   风格关键词:                                                   │
│                                                                 │
│   🎨 2D扁平卡通 + 轻魔法主题                                    │
│   ✨ 圆角大 · 阴影轻 · 布局干净                                 │
│   🌟 明亮不刺眼 · 温暖不沉重                                    │
│   💫 动效轻快 · 反馈即时                                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 设计原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **强反馈** | 每个交互都有明显反馈 | 按钮按压缩放、卡片弹跳 |
| **低密度** | 每屏信息不过载 | 每页文字不超过屏幕30% |
| **高对比** | 重要元素要突出 | 主按钮用渐变色 |
| **温和感** | 避免压力和攻击性 | 不用红色警告、不用尖锐角 |
| **游戏感** | 像游戏不像工具 | 场景插画、角色对话、动效 |

### 1.3 参考产品

| 产品 | 参考点 |
|------|--------|
| **Duolingo** | 轻量游戏化、强反馈、圆角卡片、角色陪伴 |
| **Forest** | 成长可视化、情绪价值 |
| **Headspace** | 温和配色、低压力感 |
| **Nintendo** | 清爽明亮、动效愉悦 |

### 3.5 颜色使用规范

| 场景 | 颜色 | 说明 |
|------|------|------|
| 页面背景 | `--c-bg` | 奶白色,不纯白 |
| 卡片背景 | `--c-bg-card` | 纯白,与背景形成层次 |
| 主要文字 | `--c-text` | 深蓝灰,不纯黑 |
| 主按钮 | `--gradient-btn` | 渐变金→青 |
| 次按钮 | `--c-bg-card` + `--stroke-soft` | 白色+淡边框 |
| 选中态 | `--c-gold` border | 微光金边框 |
| 成功提示 | `--c-success` | 仅用于小图标 |
| 裂隙元素 | `--c-rift` | 仅用于Rift相关 |

## 五、核心组件规范

### 5.1 对话框(DialogueBubble)

```
┌─────────────────────────────────────────────┐
│                                             │
│   ┌────┐  ┌────────────────────────────┐   │
│   │ 👤 │  │  "对话内容在这里显示..."   │   │
│   │ Arc│  │                            │   │
│   └────┘  └────────────────────────────┘   │
│                                             │
└─────────────────────────────────────────────┘

尺寸规范:
- 头像: 84rpx × 84rpx (圆形)
- 对话框圆角: 24rpx
- 对话框padding: 20rpx 24rpx
- 整体间距: 16rpx

样式:
- 头像: 渐变圆形 + 呼吸发光(Arc)
- 对话框: 白色半透明 + 淡描边
- 文字: --font-body, --c-text

动效:
- 出现: opacity 0→1 + translateY 10→0 (200ms)
- Arc头像: glowPulse呼吸 (3.5s循环)
```

```css
/* 对话框样式 */

  font-size: var(--font-body);
```

## 六、关键动效规范

### 6.1 基础过渡参数

| 动效类型 | 时长 | 缓动函数 |
|---------|------|---------|
| 淡入淡出 | 180ms | ease-out |
| 卡片弹跳 | 180ms | ease-out |
| 按压缩放 | 100-120ms | ease-out |
| 回弹 | 160-220ms | ease-out |
| 对话出现 | 200ms | ease-out |
| 气泡弹出 | 160ms | ease-out |

### 6.2 必须实现的动效

#### 对话出现

```css
@keyframes dialogueIn {
  from {
    opacity: 0;
    transform: translateY(10rpx);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

#### 卡片选中

```css
@keyframes cardBounce {
  0% { transform: scale(1); }
  50% { transform: scale(1.03); }
  100% { transform: scale(1); }
}
```

#### 气泡弹出(stagger)

```css
/* 依次弹出,每个延迟80ms */
.bubble-chip:nth-child(1) { animation-delay: 0ms; }
.bubble-chip:nth-child(2) { animation-delay: 80ms; }
.bubble-chip:nth-child(3) { animation-delay: 160ms; }

@keyframes bubbleAppear {
  from {
    opacity: 0;
    transform: scale(0.8);
  }
  to {
    opacity: 1;
    transform: scale(1);
  }
}
```

#### 裂隙击碎(最关键!)

```css
/* 第一阶段:抖动 */
@keyframes riftShake {
  0%, 100% { transform: translateX(0); }
  25% { transform: translateX(-5rpx) rotate(-1deg); }
  75% { transform: translateX(5rpx) rotate(1deg); }
}

/* 第二阶段:碎片散开 */
@keyframes riftExplode {
  to {
    opacity: 0;
    transform: scale(1.5);
    filter: blur(10rpx);
  }
}

/* 第三阶段:背景变亮 */
@keyframes brighten {
  from {
    filter: brightness(1);
  }
  to {
    filter: brightness(1.05);
  }
}
```

#### 光晕呼吸

```css
@keyframes glowPulse {
  0%, 100% {
    box-shadow: 0 0 20rpx rgba(246, 200, 95, 0.4);
  }
  50% {
    box-shadow: 0 0 35rpx rgba(246, 200, 95, 0.7);
  }
}
```

#### 光带扫过

```css
@keyframes shimmer {
  from {
    left: -100%;
  }
  to {
    left: 100%;
  }
}
```

## 九、验收标准

### 9.1 必须满足

| 验收项 | 标准 |
|--------|------|
| **一致性** | 5个页面都使用统一组件 |
| **强反馈** | 所有按钮点击有缩放反馈 |
| **击碎动效** | Daily击碎裂隙三段式必须可见 |
| **可读性** | 每页文字不超过屏幕30% |
| **像游戏** | 圆角大、颜色清爽、动效轻快 |
| **无外部依赖** | 不引用外部UI库也能有游戏感 |

### 9.2 动效检查单

- [ ] 对话出现:淡入+上移
- [ ] 卡片选中:弹跳+边框高亮
- [ ] 气泡弹出:依次弹出(80ms间隔)
- [ ] 按钮按压:缩放+阴影变化
- [ ] 裂隙击碎:抖动→碎片→背景变亮
- [ ] Arc头像:呼吸发光(3.5s)
- [ ] 主按钮成功:光带扫过

---

> 📝 **设计师笔记**: UI不是装饰,而是游戏体验的一部分。当玩家说"这个动画好爽"而不是"这个按钮好看",说明我们成功了。
