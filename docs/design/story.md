微习惯游戏用户故事

【核心要求】
- 只实现四个模块：
  1) 世界观 + 角色创建
  2) 愿望排序游戏（两两对决 + 最终拖拽到三圈命运盘）
  3) 魔法师行为工坊（召唤行为气泡 + 行为裂变 + 行为合成）
  4) 每日一张微行动卡（完成后击碎“裂隙宣言”，推进故事）
- 不做社交、不做复杂激励（排行榜/好友/分享都不要）
- 不做复杂数据分析，只做本地存储（wx.setStorageSync）
- 必须有明确可跑通的 MVP 故事闭环：7天主线章节（Day1~Day7），第7天完成后进入“下一座城”循环（愿望2）

【世界观与人物（必须体现在UI与台词里）】
世界观：
- “愿望大陆”被“裂隙之影”侵蚀，裂隙代表拖延/忙/没动力/觉得没意义。
- 用户是“微光法师”，用“微行动咒语（Tiny Spells）”修复裂隙，点亮愿望城。

主要角色（MVP只保留3个NPC）：
1) 弧光导师 Arc：克制温暖，负责主线引导与每日咒语派发
2) 魔法师 米娅 MIA：活泼发散，负责“行为工坊”的探索与炼金
3) 裂隙之影 Rift：每天出现一句阻力宣言，用户完成微行动后击碎

【页面结构（必须实现并可导航）】
- pages/onboarding/index
  - 世界观开场（3~5行文本+按钮“开始修复”）
- pages/role/index
  - 选择天赋（4选1）：火花型/潮汐型/石匠型/风行型
- pages/wishes/index
  - 愿望排序：先两两对决5~8轮得到Top排序，再进入“三圈命运盘”拖拽确认
- pages/workshop/index
  - 魔法师行为工坊：召唤气泡（随机3选1）、裂变（大→小）、合成（2→1生成新咒语）
- pages/daily/index
  - 今日一张微行动卡：展示卡片信息，按钮“开始施放”→“完成”→击碎裂隙宣言→推进Day进度

导航方式：
- 采用按钮跳转（wx.navigateTo / wx.redirectTo），并保持流程线性：
  Onboarding → Role → Wishes → Workshop → Daily
- 后续每天进入时默认进入 Daily（若尚未完成角色/愿望/卡组则自动补齐流程）

【故事状态机（必须严格实现）】
定义全局进度 state：
- day: 1~7（默认1）
- hasRole: boolean
- hasWishRank: boolean
- hasDeck: boolean
- todayDone: boolean
- currentWish: 当前核心愿望（string）
- deck: 卡组（保底/主线/彩蛋三张）
- history: 已完成记录（只需保存最近7天简要信息）

故事推进规则：
- Day1：完成角色创建 + 完成愿望排序（确定核心愿望城）→进入行为工坊→生成第一副卡组→进入Daily
- Day2~Day6：每天只做“每日一张卡”即可推进（可在工坊调整卡组，但非必需）
- Day7：完成今日卡后触发“第一座愿望城修复完成”剧情，解锁“选择下一座城”入口（即重新进入 wishes 页面选第二个核心愿望），day重置为1，保留角色天赋与已解锁咒语图鉴（轻量收集）

【愿望排序（必须是游戏，不是表单）】
1) 愿望卡池：至少提供12张默认愿望（可编辑新增）
  示例：健康/精力/财富/家庭/成长/影响力/自由/关系/专注/自律/技能/旅行
2) 两两对决：
  - 每轮随机给出两张愿望卡，用户选“更想靠近的那个”
  - 进行7轮（可配置），统计胜场作为排序权重
3) 命运盘拖拽：
  - Top 1 自动进入“核心愿望”
  - Top 2~3 进入“主线愿望”
  - 其余进入“以后再说”
  - 用户可以拖拽调整核心愿望（至少支持核心愿望替换）
4) 确认后，生成“愿望城名称”并存储 currentWish

【行为工坊玩法（必须可操作）】
目标：让用户“像玩游戏一样探索行为”，不是输入。
核心交互：
1) 召唤灵感：
  - 点击按钮“召唤灵感”出现3个行为气泡（从行为库按愿望分类随机）
  - 用户选择1个加入“素材区”
2) 行为裂变：
  - 用户从素材区选择一个“较大行为”点击“裂变”
  - 系统生成3个更小行为供选择（从裂变规则库匹配）
3) 行为合成：
  - 用户选择两个行为点击“合成”
  - 系统产出一个新咒语卡名称（拼接+模板命名）
产出：
- 只生成三张卡形成 deck：
  - 保底卡：30~60秒，难度★
  - 主线卡：2~5分钟，难度★★
  - 彩蛋卡：10~30秒，趣味性
卡结构必须包含：
  { id, name, desc, seconds, difficulty, type: 'base'|'main'|'bonus', wish, createdAt }

【每日一张卡（必须具备“击碎裂隙宣言”反馈）】
1) 每天只呈现一张卡（从deck中按规则抽取）：
  - 默认抽保底卡；若连续2天完成则有30%概率抽主线卡；彩蛋卡为10%概率替换
2) 完成流程：
  - 点击“开始施放” → 显示简短引导（不超过1句话）
  - 点击“完成” → 展示裂隙宣言（从阻力池随机） → 点击“击碎” → 显示导师一句鼓励台词
3) 若用户当天未完成（todayDone=false），第二天自动降级为“救援卡”（从保底卡或预置救援卡池抽取）
4) 完成后推进 day +1（最大7），并写入history（日期、卡名、耗时秒数）
