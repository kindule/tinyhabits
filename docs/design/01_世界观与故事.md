# 🌍 世界观与故事设计

> 在游戏设计中,世界观不是装饰,而是让玩家"相信"的理由。好的世界观让日常行为变得有意义。

---

## 一、世界观概述

### 1.1 世界名称

**「愿望大陆」** (Wish Continent)

> 每个人内心都有一片属于自己的愿望大陆。这片大陆上散布着许多愿望城,每座城代表人生中的一个核心愿望:健康、成长、财富、自由、家庭、探索...

### 1.2 核心冲突

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   「裂隙之影」正在侵蚀愿望大陆                                  │
│                                                                 │
│   裂隙 = 拖延 / 太忙 / 没动力 / 觉得没意义 / 完美主义          │
│                                                                 │
│   愿望城被裂隙覆盖 → 变成荒地 → 逐渐被遗忘                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 玩家身份

**「微光法师」** (Tiny Spark Mage)

> 你不是拯救世界的英雄,而是点亮微光的修炼者。
> 
> 微光法师的力量不在于强大,而在于**微小但持续**。
> 每一个微行动咒语,都是一束穿透裂隙的微光。

### 1.4 核心隐喻

| 现实概念 | 游戏表达 | 设计意图 |
|---------|---------|---------|
| 人生愿望 | 愿望城 | 将抽象愿望可视化 |
| 习惯行为 | 微行动咒语 | 赋予日常行为魔法感 |
| 拖延阻力 | 裂隙之影 | 外化内心阻力,可被击败 |
| 完成习惯 | 击碎裂隙 | 赋予完成动作仪式感 |
| 持续7天 | 修复愿望城 | 赋予阶段性成就感 |
| 锚点提示 | ✨ 时机魔法 | 让触发提示有仪式感 |

### 3.2 Arc · 弧光导师 🌟

#### 形象设定

```
视觉: 金色渐变圆形 + 两个白色眼睛点 + 呼吸发光效果
气质: 温暖但克制,像一位智慧的老友
声线: 平静、笃定、不急不躁
```

#### 性格特征

| 特征 | 体现 |
|------|------|
| **克制温暖** | 从不说"加油""你真棒"这类空洞鼓励 |
| **智慧平和** | 用问题引导思考,而非直接给答案 |
| **始终相信** | 即使用户断签,也温和地等待归来 |
| **言语精炼** | 每句话不超过20字,留白胜过啰嗦 |

#### 核心台词风格

```
✅ Arc风格:
"你不需要更努力,你需要更小一点。"
"最难的一步,不是跑完全程,是穿上跑鞋。"
"微光不会因为休息而消失。"

❌ 避免:
"太棒了!你真厉害!"      → 过于空洞
"继续加油哦~"           → 过于轻浮
"你怎么又没完成?"       → 带有责备
```

#### 出场时机

| 场景 | Arc登场 |
|------|---------|
| 世界观开场 | ✅ 欢迎玩家 |
| 角色创建 | ✅ 介绍天赋 |
| 愿望排序完成 | ✅ 确认核心愿望 |
| 每日完成微行动 | ✅ 鼓励台词 |
| Day 7完成 | ✅ 里程碑庆祝 |
| 用户断签回归 | ✅ 温和迎接 |

---

### 3.3 MIA · 魔法师米娅 ✨

#### 形象设定

```
视觉: 青蓝渐变圆形 + 星形贴片 + 活泼跳动动效
气质: 好奇、活泼、创意满满的年轻魔法师
声线: 轻快、跳跃、偶尔有点小孩子气
```

#### 性格特征

| 特征 | 体现 |
|------|------|
| **好奇发散** | "咦?如果把这两个行为合起来呢?" |
| **鼓励探索** | "试试看嘛~反正只是素材!" |
| **减少压力** | "不用想太多,先收集起来!" |
| **创意引导** | "如果只要30秒呢?如果不出门呢?" |

#### 核心台词风格

```
✅ MIA风格:
"让我为你召唤一些灵感泡泡~"
"裂变启动!把宏大计划拆成一步就行!"
"那就让它更小,小到无法拒绝~"

❌ 避免:
"你必须选择一个"        → 过于强制
"这个不太好"           → 否定用户
"快点完成"             → 制造压力
```

#### 出场时机

| 场景 | MIA登场 |
|------|---------|
| 行为工坊 | ✅ 主导全程 |
| 召唤灵感 | ✅ 引导选择 |
| 行为裂变 | ✅ 解释拆分 |
| 行为合成 | ✅ 庆祝创造 |
| AI对话 | ✅ 作为AI的拟人化声音 |
| Day 4/5 | ✅ 特定剧情 |

---

### 3.4 Rift · 裂隙之影 🌑

#### 形象设定

```
视觉: 紫黑渐变圆形 + 两个紫色眼睛点 + 出现时抖动
气质: 诱惑、低语、似敌非敌
声线: 低沉、轻柔、像耳边的杂念
```

#### 设计哲学

> **Rift不是敌人,而是"需要被照亮的阴影"。**
> 
> 它代表每个人内心的阻力声音。玩家击碎裂隙,不是"消灭敌人",而是"承认阻力存在,然后选择继续"。

#### 性格特征

| 特征 | 体现 |
|------|------|
| **诱惑低语** | 像耳边的杂念,合理但消极 |
| **不羞辱** | 从不说"你真没用",只说"算了吧" |
| **可被击碎** | 每句宣言都能被一次微行动打破 |
| **永远存在** | 即使被击碎,明天还会再来 |

#### 核心台词风格(裂隙宣言)

```
✅ Rift风格(可被击碎的轻量阻力):
"今天太累了,算了吧..."
"这点做了也没用..."
"明天再开始也行..."
"完美的时机还没到..."
"状态不好,改天吧..."

❌ 避免(过于负面,不使用):
"你这么懒,注定失败"     → 羞辱
"你永远做不到"          → 否定
"别人都比你强"          → 攀比
```

#### 出场时机

| 场景 | Rift登场 |
|------|---------|
| 每日完成前 | ✅ 裂隙宣言卡滑入 |
| Day 2/4 | ✅ 特定剧情台词 |
| 关键对抗 | ✅ 作为阻力象征 |

## 四、天赋体系

### 4.1 四大天赋

> 天赋不决定玩家能力,而是**让玩家感受到"被理解"**。
> 
> 不同天赋影响:开场台词、行为推荐偏好(未来)、界面主题色(未来)。

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   🔥 火花型            🌊 潮汐型                               │
│   Spark               Tide                                      │
│                                                                 │
│   "我喜欢快速行动,     "我喜欢顺其自然,                        │
│    短平快的小任务"      随心情变化的节奏"                       │
│                                                                 │
│   ──────────────────  ──────────────────                       │
│                                                                 │
│   🪨 石匠型            🍃 风行型                               │
│   Mason               Wind                                      │
│                                                                 │
│   "我喜欢稳定节奏,     "我喜欢灵活多变,                        │
│    每天固定的习惯"      探索不同可能性"                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 天赋详情

| 天赋 | 关键词 | 描述 | 推荐行为类型 |
|------|--------|------|-------------|
| 🔥 **火花型** | 快/短/爆发 | 喜欢短平快,一闪而过的微行动 | 5-30秒的瞬间行为 |
| 🌊 **潮汐型** | 流/顺/自然 | 喜欢顺应状态,随心情调整 | 可伸缩的弹性行为 |
| 🪨 **石匠型** | 稳/固/持续 | 喜欢固定时间固定动作 | 锚点明确的稳定行为 |
| 🍃 **风行型** | 变/探/多样 | 喜欢尝试新东西,害怕重复 | 每天不同的新鲜行为 |

## 六、叙事设计原则

### 6.1 叙事风格

| 原则 | 说明 | 示例 |
|------|------|------|
| **精炼** | 每句话不超过20字 | ✅ "微光不会消失" ❌ "你的微光永远不会因为任何原因而消失的哦" |
| **温和** | 不惩罚、不羞辱 | ✅ "救援咒语已准备好" ❌ "你昨天没完成" |
| **隐喻** | 用游戏语言表达 | ✅ "击碎裂隙" ❌ "完成任务" |
| **留白** | 不解释所有事情 | 让玩家自己体会意义 |

### 6.2 对话结构

```
标准对话结构:

[角色头像] 
角色名: "第一句话。"
角色名: "第二句话(可选)。"

每次对话:
- 最多2句
- 每句不超过20字
- 关键词用引号强调
```

### 6.3 情绪曲线

```
7天主线情绪曲线:

Day 1: 新鲜 + 期待      ↗️  "欢迎成为微光法师"
Day 2: 第一次阻力      ↘️  Rift首次出现
Day 3: 小成就感        ↗️  "你做到了最难的一步"
Day 4: 质疑期          ↘️  "这点做了也没用"
Day 5: 转折点          ↗️  MIA裂变引导
Day 6: 稳定期          ➡️  "形成自己的节奏"
Day 7: 里程碑 🎉       ⬆️  "第一座愿望城修复完成!"
```

---

> 📝 **设计师笔记**: 世界观的目的不是"让用户相信魔法存在",而是"让用户的日常行为变得有意义"。当用户说"我今天要击碎裂隙"而不是"我今天要打卡",说明世界观成功了。
