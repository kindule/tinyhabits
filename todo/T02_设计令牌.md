# T02: 设计令牌与样式变量

> **优先级**: P0 (必须实现)
> **预估工时**: 0.5天
> **负责人**: 前端开发
> **状态**: ✅ DONE

---

## 一、任务描述

在`app.wxss`中定义全局CSS变量(设计令牌)，统一管理颜色、字体、间距、圆角、阴影等视觉规范。

---

## 二、验收标准

- [ ] 所有CSS变量按规范定义在`app.wxss`的`:root`中
- [ ] 颜色变量包含：基础色、魔法主题色、状态色
- [ ] 字体变量包含：字号层级、字重、行高
- [ ] 尺寸变量包含：间距、圆角、阴影
- [ ] 渐变变量包含：场景渐变、按钮渐变
- [ ] 创建颜色预览页面验证变量正确性

---

## 三、技术实现

### 3.1 完整的app.wxss设计令牌

```css
/* ==================== */
/* 设计令牌 Design Tokens */
/* ==================== */

page {
  /* ===== 尺寸与间距 ===== */
  --page-pad: 32rpx;           /* 页面内边距 */
  --scene-h: 280rpx;           /* 顶部场景高度 */
  --footer-h: 140rpx;          /* 底部操作栏高度 */
  
  /* 圆角 */
  --radius-card: 28rpx;        /* 卡片圆角 */
  --radius-btn: 999rpx;        /* 按钮圆角(药丸形) */
  --radius-bubble: 999rpx;     /* 气泡圆角 */
  --radius-sm: 16rpx;          /* 小圆角 */
  
  /* 间距 */
  --gap-xs: 8rpx;              /* 极小间距 */
  --gap-sm: 12rpx;             /* 小间距 */
  --gap-md: 20rpx;             /* 中间距 */
  --gap-lg: 32rpx;             /* 大间距 */
  --gap-xl: 48rpx;             /* 特大间距 */
  
  /* 内边距 */
  --card-pad: 24rpx;           /* 卡片内边距 */
  --btn-pad-h: 32rpx;          /* 按钮水平内边距 */
  --btn-pad-v: 24rpx;          /* 按钮垂直内边距 */
  
  /* ===== 字体层级 ===== */
  --font-h1: 44rpx;            /* 大标题 */
  --font-h2: 34rpx;            /* 小标题 */
  --font-body: 28rpx;          /* 正文 */
  --font-sub: 24rpx;           /* 辅助文字 */
  --font-cap: 22rpx;           /* 标签/备注 */
  
  /* 字重 */
  --weight-bold: 600;          /* 粗体 */
  --weight-medium: 500;        /* 中粗 */
  --weight-regular: 400;       /* 常规 */
  
  /* 行高 */
  --line-h-title: 1.2;         /* 标题行高 */
  --line-h-body: 1.5;          /* 正文行高 */
  
  /* ===== 阴影与描边 ===== */
  --shadow-card: 0 12rpx 30rpx rgba(0, 0, 0, 0.06);
  --shadow-btn: 0 10rpx 24rpx rgba(0, 0, 0, 0.08);
  --shadow-float: 0 8rpx 20rpx rgba(0, 0, 0, 0.12);
  
  /* 描边 */
  --stroke-soft: 1rpx solid rgba(31, 42, 55, 0.06);
  --stroke-active: 2rpx solid var(--c-gold);
  
  /* ===== 基础色 ===== */
  --c-bg: #FAFBFF;              /* 奶白色背景 */
  --c-bg-card: #FFFFFF;         /* 卡片白色 */
  
  /* 文字 */
  --c-text: #1F2A37;            /* 深蓝灰主文字 */
  --c-subtext: rgba(31, 42, 55, 0.65);  /* 次文字 */
  --c-hint: rgba(31, 42, 55, 0.45);     /* 提示文字 */
  
  /* 线条 */
  --c-line: rgba(31, 42, 55, 0.10);     /* 分割线 */
  --c-border: rgba(31, 42, 55, 0.08);   /* 边框 */
  
  /* ===== 魔法主题色 ===== */
  /* 微光金 - 主色调 */
  --c-gold: #F6C85F;
  --c-gold-light: rgba(246, 200, 95, 0.18);
  
  /* 湖蓝 - 辅助色 */
  --c-cyan: #5EC8D8;
  --c-cyan-light: rgba(94, 200, 216, 0.18);
  
  /* 柔紫 - 点缀色 */
  --c-purple: #8A7DFF;
  --c-purple-light: rgba(138, 125, 255, 0.18);
  
  /* ===== 状态色 ===== */
  /* 成功 */
  --c-success: #2ECC71;
  --c-success-light: rgba(46, 204, 113, 0.12);
  
  /* 警示 */
  --c-warn: #FFB020;
  --c-warn-light: rgba(255, 176, 32, 0.12);
  
  /* 裂隙 */
  --c-rift: #2B1B3D;
  --c-rift-light: rgba(43, 27, 61, 0.85);
  
  /* ===== 场景渐变 ===== */
  --gradient-home: linear-gradient(180deg, rgba(94, 200, 216, 0.26), rgba(250, 251, 255, 1));
  --gradient-workshop: linear-gradient(180deg, rgba(138, 125, 255, 0.22), rgba(250, 251, 255, 1));
  --gradient-daily: linear-gradient(180deg, rgba(246, 200, 95, 0.28), rgba(250, 251, 255, 1));
  
  /* 主按钮渐变 */
  --gradient-btn: linear-gradient(90deg, #F6C85F, #5EC8D8);
  
  /* ===== 动效时长 ===== */
  --duration-fast: 100ms;
  --duration-normal: 180ms;
  --duration-slow: 300ms;
}

/* ===== 全局基础样式 ===== */
page {
  background-color: var(--c-bg);
  color: var(--c-text);
  font-size: var(--font-body);
  line-height: var(--line-h-body);
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;
}

/* 页面容器 */
.page {
  min-height: 100vh;
  padding: var(--page-pad);
  box-sizing: border-box;
  display: flex;
  flex-direction: column;
}

/* 安全区底部 */
.safe-bottom {
  padding-bottom: constant(safe-area-inset-bottom);
  padding-bottom: env(safe-area-inset-bottom);
}
```

### 3.2 颜色使用规范表

| 场景 | 变量名 | 说明 |
|------|--------|------|
| 页面背景 | `--c-bg` | 奶白色，不纯白 |
| 卡片背景 | `--c-bg-card` | 纯白，与背景形成层次 |
| 主要文字 | `--c-text` | 深蓝灰，不纯黑 |
| 次要文字 | `--c-subtext` | 65%透明度 |
| 主按钮 | `--gradient-btn` | 渐变金→青 |
| 次按钮 | `--c-bg-card` + `--stroke-soft` | 白色+淡边框 |
| 选中态 | `--c-gold` | 微光金边框 |
| 裂隙元素 | `--c-rift` | 仅用于Rift相关 |

## 六、备注

- CSS变量使用`page`选择器而非`:root`，因为小程序不支持`:root`
