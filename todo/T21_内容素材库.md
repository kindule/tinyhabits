# T21: 愿望库与行为库

> **优先级**: P0 (必须实现)
> **预估工时**: 2天
> **负责人**: 内容/全栈开发
> **状态**: ✅ DONE

---

## 一、任务描述

创建游戏所需的内容素材库，包括愿望卡数据、行为库数据、台词库等静态内容。

---

## 二、验收标准

- [ ] 6个愿望卡
- [ ] 每个愿望对应5-10个行为
- [ ] 行为包含裂变规则
- [ ] Day1-7台词完整
- [ ] 裂隙宣言池
- [ ] 鼓励台词池

---

## 三、数据结构

### 3.1 愿望卡结构

```javascript
{
  id: string,           // 唯一标识
  name: string,         // 愿望名称
  icon: string,         // emoji图标
  desc: string,         // 描述
  cityName: string,     // 愿望城名称
  category: string,     // 分类
  keywords: string[]    // 关键词(用于匹配)
}
```

### 3.2 行为结构

```javascript
{
  id: string,           // 唯一标识
  name: string,         // 行为名称
  category: string,     // 所属愿望分类
  seconds: number,      // 预计时长(秒)
  difficulty: number,   // 难度(1-3)
  splitTo: string[],    // 裂变目标ID列表(可选)
  tags: string[]        // 标签
}
```
